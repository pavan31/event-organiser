# event-organiser

# Frontend

This is the frontend of the Event Registration application built using **React, Material UI, and React Router**.

## Features
- Display a list of events in a grid format.
- Create a new event with static and dynamic fields.
- Register for an event with static and dynamic fields.
- View all event registrations in a report table.
- Navigation for different pages.

## Tech Stack
- React.js
- Material UI
- React Router
- Axios for API requests

## Installation
1. Navigate to the `frontend` directory:
   ```sh
   cd frontend
2. npm install
3. npm start


# Backend

This is the backend for the Event Registration application, built using **Node.js, Express, and MongoDB**.

## Features
- Create and store event details with static and dynamic fields.
- Register users for events and store responses dynamically.
- Fetch events and registrations via REST APIs.

## Tech Stack
- Node.js
- Express.js
- MongoDB with Mongoose
- CORS for cross-origin requests
- dotenv for environment variables

## Installation
1. Navigate to the `backend` directory:
   ```sh
   cd backend
2.npm install
3.npm run dev
